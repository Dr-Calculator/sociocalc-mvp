# SocioCalc MVP

SocioCalc is a financial literacy and community empowerment web app designed to help students and communities manage money wisely and prepare for emergencies.

## 🌟 Features
- **Learning Hub**: Actuarial concepts explained simply.
- **Quizzes**: Practice and test your knowledge.
- **Loan Calculator**: Calculate repayment schedules.
- **Savings Calculator**: Track savings growth.
- **Budget Tracker**: Plan and monitor expenses.
- **SACCO Ledger**: Manage group savings and loans.
- **Mentorship Platform**: Connect learners with mentors.
- **Financial Literacy Modules**: Budgeting, saving, debt management.
- **Disaster Preparedness**: Tips for financial resilience in emergencies.
